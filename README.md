## O que tem neste repositório

- `site/index.html`: a página principal do site da Nexo Company.
- `site/style.css`: o visual do site (cores, tamanhos e posição dos elementos).
- `site/nexo_loop.mp4`: o vídeo que aparece no topo da página.
- `site/Logonexo.jpg`: o logo usado na página.
- `Logonexo.jpg`: uma cópia do logo na raiz do projeto.
- `.vscode/launch.json`: configuração para abrir o site no VS Code com o Chrome.

## Como abrir o site

1. Clique no botão verde **Code** e depois em **Download ZIP**.
2. Extraia o arquivo ZIP em uma pasta do computador.
3. Abra a pasta `site` e dê dois cliques em `index.html`. A página vai abrir no navegador.

Obs.: o GitHub mostra o código do arquivo, e não a página. Para ver o site funcionando, abra o arquivo no navegador, como no passo 3.
